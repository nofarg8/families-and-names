# מאיפה באנו?

אפליקציית משחק ושיחה על מוצאי יהודים ושמות משפחה, למשתמש מבוגר. מובייל פירסט, RTL, PWA, בלי שרת. כל המידע נשמר רק במכשיר.

האפיון המלא: [maeifo-banu-spec.md](maeifo-banu-spec.md)

## מה בנוי (שלב 1)

- מסך בית עם ברכה לפי שעה ושם המשתמש
- "מאיפה השם?": 5 שמות בכל משחק, 3 אפשרויות, משוב חם בלי "טעות", הערה אישית "אני מכיר משפחה כזו", מסך סיום עם שיתוף
- "הסיפור שלי": שאלה אחת בכל מסך, שמירה, דילוג, "ספר המשפחה" עם עריכה, מחיקה ושיתוף (Web Share, או העתקה כשאין)
- הגדרות: גודל טקסט (100% / 125% / 150%), שם, הקראה אוטומטית ומהירות
- הקראה (he-IL) שמוסתרת אם אין קול עברי במכשיר
- PWA: התקנה למסך הבית ועבודה בלי אינטרנט אחרי טעינה ראשונה. הגופנים מוטמעים מקומית

## הרצה

```bash
npm install
npm run dev
```

בנייה: `npm run build`. אייקונים מחדש מ-`public/icon.svg`: `npm run icons`.

## תוכן

כל התוכן ב-`src/data` מסומן `"verified": false` ומנוסח בזהירות ("נפוץ במיוחד אצל"). צריך לאמת מול מאגר שמות המשפחה של אנו - מוזיאון העם היהודי לפני שמסמנים `true`.

המחרוזות בממשק נמצאות ב-`src/i18n/he.json`, מוכנות להוספת רוסית.
